## What is metadata?
Metadata is data that describes other data. In a RAG system, metadata provides additional information about a document or chunk, such as the source file, page number, author, title, or publication date.

## Why is metadata usefull in RAG?
Metadata helps identify where retrieved information came from. It improves traceability, source attribution, filtering, and user trust by allowing answers to be linked back to their original documents.
## What information can metadata store?
source
page number
author
title
publication date
document type
chunk id
section name

## Why should answers show sources?
Showing sources increases transparency and trust. Users can verify the information, check the original context, and determine whether the retrieved information is reliable.
