## what is an LLM?
LLM is like brain of the model it contains pre trained and fine tuned neural network model which is used to answer question based on the knowledge it has been trained on.

It predicts the most likely sequence of words that should come next based on everything it learned during training.

## What are Tokens?

LLMs don't read actual words, they read tokens.
A token is a small chunk of text.

## What is a Context Window?
It is a working memory for an LLM model during a conversation.
